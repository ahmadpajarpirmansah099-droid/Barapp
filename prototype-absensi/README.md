# Barapp — Absensi UI Preview

Vite-only frontend prototype for reviewing a visual redesign of the Absensi module.

## Run locally
```bash
npm install
npm run dev
```

## Important boundaries
- This prototype is isolated in `prototype-absensi/`.
- It uses sample data only and does not import or call Barapp/Supabase code.
- No production HTML, JavaScript logic, permissions, data, or backend paths are changed.
- Buttons are visual interaction placeholders. Production handlers must be preserved and reattached when the approved design is ported into `index.html`.
